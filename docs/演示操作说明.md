# 演示操作说明

## 演示前准备

1. 推荐使用 1440px 左右的桌面浏览器窗口，浏览器缩放保持 100%。
2. 打开首页后点击右上角“重置”。
3. 确认左侧“本轮进度”为 0/5，首页材料框为空。
4. 关闭无关通知和浏览器扩展弹窗。
5. 演示全程不需要外部网络或真实 AI 服务。

## 标准主路线

### A. 材料与选题

1. 点击“加载示例材料”。
2. 确认出现“材料已就绪”。
3. 点击“分析并生成选题”。
4. 在候选选题页确认第一条为 91 分。
5. 点击第一条“查看评分依据”，展示四维评分与证据来源。

### B. 细分与脚本

1. 点击第一条“选择这个选题”。
2. 在细分版本中选择第一项“一个人夜间照护，翻身太累”。
3. 保持“真人脚本”模式。
4. 点击“生成真人脚本”。
5. 向下浏览 6 个镜头，重点展示第 3、4 镜中的预置风险表述。
6. 如需展示 AIGC，点击“AIGC Prompt”标签，展示 5 个镜头及连贯性约束后切回。

### C. 风险与发布

1. 点击“检测内容”。
2. 等待出现“发现 2 处需要修改”。
3. 对照展示修改前、修改后及风险原因。
4. 点击“应用 2 处安全修改”。
5. 确认页面显示检测通过。
6. 点击“确认并标记发布”。
7. 保持“视频号”、`2026-09-09` 和“这条内容已真实发布”，点击确认。

### D. 反馈与经验

1. 在内容任务页点击“载入演示反馈”。
2. 确认数据为：播放量 4,280、完播率 31%、高意向咨询 3 次。
3. 点击“提交反馈并形成经验”。
4. 在内容经验页指出“第 3 次有效观察”和“已验证策略”。

## 备用路线

如果时间只剩 2 分钟：

1. 首页直接点击“生成今日选题”。
2. 选择第一条选题与第一项细分版本。
3. 生成真人脚本。
4. 完成风险检测和一键修改。
5. 口头说明发布反馈环节，不再逐页展开。

## 现场恢复

- 操作到了错误页面：使用左侧“创作工作台”返回，系统会保留当前进度。
- 浏览器刷新：状态保存在当前浏览器中，刷新后仍会保留。
- 想从头开始：点击右上角“重置”。
- 按钮暂时不可用：等待不足 1 秒的演示生成状态结束后再操作。
- 移动端找不到导航：点击左上角菜单按钮打开侧栏。

## 不建议现场改动

- 不要临时输入未经准备的长材料；演示结果仍会使用稳定候选数据。
- 不要取消“这条内容已真实发布”，否则反馈不会进入经验学习。
- 不要在风险修改前直接发布；页面会提示先完成检测。
